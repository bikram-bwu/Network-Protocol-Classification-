# Network Protocol Classification

## Project Overview
This project focuses on Network Protocol Classification using Machine Learning techniques.

The objective is to analyze network traffic data and classify network protocols based on the available dataset features.

## Dataset Information
- Dataset Name: KT_GameBox_1.csv
- Total Rows: 100,000
- Total Columns: 7

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Machine Learning

## Machine Learning Models
Multiple Machine Learning models are evaluated to classify network protocols.

Decision Tree is one of the models used in this project.

## Project Workflow
1. Dataset Upload
2. Data Exploration
3. Missing Value Checking
4. Data Preprocessing
5. Exploratory Data Analysis
6. Model Training
7. Model Evaluation
8. Protocol Prediction

## Sample Prediction
Predicted Protocol: UDP
